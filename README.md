# restaurant-final

Eats N Bites — Full-Stack Restaurant Ordering System & Kitchen Console

## Tech Stack
- **Frontend**: Next.js 14, React, Tailwind CSS, Lucide Icons
- **Backend**: Node.js, Express.js, MongoDB Atlas (Mongoose)
- **Features**:
  - Live Menu with categories, customization options, and variants
  - Instant Cart & Checkout with COD support
  - Real-time Order Tracking by Order Reference (`ENB-XXXXXX`)
  - Internal Kitchen & Dispatch Console (`/admin`) connected directly to MongoDB
